# E-commerce project

Проект для домашнего задания по ООП.

## Описание

В проекте реализованы базовые сущности интернет-магазина:

- `Product` — товар;
- `Category` — категория товаров.

## Класс `Product`

Класс `Product` описывает товар.

Атрибуты:

- `name` — название товара;
- `description` — описание товара;
- `price` — цена товара;
- `quantity` — количество товара в наличии.

Пример:

```python
from src.classes import Product

product = Product(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5,
)

## Домашнее задание 16.1

В проект добавлены классы-наследники и ограничения для работы с объектами разных типов.

### Класс `Smartphone`

Класс `Smartphone` наследуется от `Product`.

Дополнительные атрибуты:

- `efficiency` — производительность;
- `model` — модель;
- `memory` — объем встроенной памяти;
- `color` — цвет.

### Класс `LawnGrass`

Класс `LawnGrass` наследуется от `Product`.

Дополнительные атрибуты:

- `country` — страна-производитель;
- `germination_period` — срок прорастания;
- `color` — цвет.

### Ограничение сложения

Метод `__add__` доработан так, что складывать можно только товары одинаковых классов.

Например:

- `Product + Product` — можно;
- `Smartphone + Smartphone` — можно;
- `LawnGrass + LawnGrass` — можно;
- `Smartphone + LawnGrass` — нельзя.

При попытке сложить товары разных классов выбрасывается `TypeError`.

### Ограничение добавления товаров

Метод `add_product` класса `Category` доработан так, что в категорию можно добавлять только объекты класса `Product` или его наследников.

При попытке добавить другой объект выбрасывается `TypeError`.
